## 🚀 Tính năng nổi bật của Website

1. **Giao diện Giọt nước (Liquid Droplet Islands):**
   - Thanh taskbar chia nhỏ dạng module lơ lửng, hỗ trợ điều hướng mượt mà.
2. **Hiệu ứng Scroll 2 chiều (Scroll-Driven Reveal & Exit):**
   - Tự động hiện mượt mà khi cuộn tới và thu gọn tinh tế khi lướt qua.
3. **Bố cục 3 Cánh Sân khấu (Hero Theater):**
   - Cánh trái: Tư duy chiến lược & Storytelling.
   - Trung tâm: Chân dung cử nhân FPT University với ánh hào quang ambient.
   - Cánh phải: Tiêu điểm dự án Workshop Lumora Studio.
4. **Showcase Thực chiến:**
   - Ảnh chụp bài viết truyền thông đã được tối ưu, sạch sẽ và sắc nét.
   - Bảng phân tích vai trò và chỉ số tương tác chiến dịch.

## 🌐 Triển khai GitHub Pages

Trang web tương thích 100% với **GitHub Pages**:
1. Vào **Settings** > **Pages** trên repository.
2. Chọn branch `main` (hoặc `master`), thư mục `/ (root)`.
3. Bấm **Save**. Website sẽ hoạt động trực tiếp tại:
   `https://catquynhnp.github.io/-Portfolio/`
